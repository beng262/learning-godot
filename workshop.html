The workshop

A small working copy of the Godot editor, in the page. Build a scene, set properties in the Inspector, attach scripts, connect signals, and press Run.

What you can do here

  • find your way round the editor's docks before you open the real one
  • add, rename, move and delete nodes, and watch the .tscn file change
  • write a script, attach it to a node and run the scene
  • connect a signal from the Node dock and see the method it calls

The editor

The layout is Godot's own: the scene on the left, the view in the middle, the Inspector on the right and the Output underneath. A small game is already loaded – press ▶ Run and walk with the arrow keys.

A teaching model, not the engine

It knows seven node types – Node, Node2D, Sprite2D, ColorRect, Label, Button and Timer – and has no physics or resources. What it gets right is where things are and what they are called, so the real editor looks familiar the first time you open it. Your scene is kept in this browser; Start over brings back the one it started with.

Find your way round

Five short tasks, each using one part of the editor. Do them in order the first time.

  1. Run it

    Press ▶ Run. The Output prints Hello from Player once and a tick every second. Walk the player onto the coin with the arrow keys and the score goes up; press Spin and it turns. Press ■ Stop when you are done – while a scene runs, the editor shows it as it is, and stopping puts every property back.

  2. Select and change

    Click Coin in the Scene dock. The Inspector shows its properties, grouped by the class that adds them: texture comes from Sprite2D, position and scale from Node2D. Change scale to (3, 3), or drag the coin in the view. Then open Scene file (.tscn) under the view: only the properties you changed from their defaults are written down.

  3. Add a child

    Select Main, press ＋ Add, search for ColorRect and pick it. It is added as a child of the selected node. Double-click its name to rename it Floor, and give it a colour and a size in the Inspector. The tree order is the drawing order, so a node lower in the list draws on top.

  4. Read a script

    Select Player and open the Script tab. _ready() runs once when the node enters the tree; _process(delta) runs every frame. Change speed from 90.0 to 200.0 and run again. Because it is an @export variable, the real editor also shows it in the Inspector, so a designer can tune it without opening the script. (The workshop's Inspector shows only the node's own properties.)

  5. Connect a signal

    Select Tick and switch the right-hand dock to Node. Its timeout signal is already connected to _on_tick_timeout on Main – that is the [connection] line at the bottom of the .tscn. The Spin button is connected the other way, in code, by $Spin.pressed.connect(...) in Main's _ready(). Both are ordinary in Godot; disconnect the timer here and run again to see the ticks stop.

Things to try

Once the tasks feel easy, change the game.

  • Add a second coin: select Coin, press Duplicate, and make Main's script check both.
  • Add a Timer with one_shot on and wait_time of 10, connect its timeout, and end the game with a message in the Score label.
  • Make the Spin button flip the player with flip_h instead of turning it.
  • Break something on purpose – a misspelt $Path, a missing method – and read what the Output says. The real editor's errors read the same way.
