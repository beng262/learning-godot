Learning Godot by reading one game

Most engine tutorials build a toy and stop. This one takes a finished game — twelve thousand lines, twenty-five rooms, a cast of nine — and opens it up. You get the engine explained, the game explained, and twenty-six exercises that end in something you can run.

How to read this

Front to back if you are new to Godot. Straight to Part II if you already know the engine and want to see how a real project is put together. Straight to Part III if you would rather learn by breaking something.

The game is Tiny Home: a cozy life-sim where you have bought a fixer-upper on the edge of a small town. It is a real project rather than a teaching example — it has awkward corners, a few things done twice before they were done right, and comments explaining why. That is the point. Reading a finished thing teaches you what a tutorial cannot: what the decisions cost.

Everything here is measured against the actual code as it stands today. Where a number appears, it came from running something, not from memory.

You do not need the game to read this

Every chapter stands on its own, and the code is quoted in place. But if you want to run the exercises you need the project and a copy of Godot 4.7 — Chapter 1 covers getting both.
