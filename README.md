# Learning Godot by Reading One Game

A short book on Godot 4, taught through one finished game — a cozy life-sim
called Tiny Home.

**Read it: https://beng262.github.io/learning-godot/**

Four parts:

- **I · The engine** — nodes, scenes, signals, GDScript, and the project
  settings that decide whether pixel art looks like pixel art
- **II · This game** — the eight mechanisms doing all the work, with annotated
  screenshots and the code
- **III · Your turn** — graded exercises, each ending in something runnable
- **IV · Shipping** — exporting, publishing on itch.io, licensing

## About the game

Tiny Home is a private project. This repository holds only the book: the
teaching text, four screenshots, and short code excerpts quoted to explain a
point. The game's source, art and story are not here.
