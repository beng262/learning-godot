# Godot from A to Z

A book you can run: Godot 4, one letter at a time, with live tutorials and a
real game – a cosy life game called Little Hours – opened up beside it.

**Read it: https://beng262.github.io/learning-godot/**

- **26 chapters, A to Z**, in six parts – from what an engine is to exporting
  and shipping. Each has a live tutorial, the place its idea lives in the game,
  exercises and a recap.
- **Live tutorials.** One editor, a few steps: your GDScript runs as you type,
  each step's checks tick as you meet them, and the next step opens when they
  pass. It runs in the browser on a small interpreter written for the book, so
  nothing needs installing.
- **Little Hours from A to Z** – the game one rule at a time, from Animals to
  Zzz: what the player sees, the rule with its numbers, the code that ships, and
  a tutorial that rebuilds the rule in miniature.
- **The workshop** – a small working copy of the Godot editor in the page.
- **Inside the code** – every file of the game, what it does and why.

Progress is kept in your browser only. Nothing is sent anywhere.

## About this repository

This is the built book: plain HTML, CSS and JavaScript, served as it is by
GitHub Pages. It is generated from the game's own repository, where code is
quoted from the game when the book is built, so the code in these pages is the
code that ships. Little Hours itself – its full source, art and story – is not
here.

The old pages of the first edition (`godot.html`, `game.html`,
`exercises.html`, `shipping.html`) now forward to their new homes.
